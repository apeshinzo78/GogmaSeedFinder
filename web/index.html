メモ推奨基準seedと2つのカウンターはこのブラウザに自動保存されます。ブラウザのデータ削除や端末変更に備え、セーブ状態コードも別途控えてください。

基準seed・各カウンターを手入力で設定

すでに値が分かっている場合は、検索せずに現在のセーブ状態へ設定できます。 分からないカウンターは空欄のままにできます。

セーブ状態コードで引き継ぐ

状態コードは基準seedと特定済みカウンターをまとめた、このツール専用の引き継ぎコードです。

HOW IT WORKS

基準seedと2つのカウンター

セーブ固有seed＋2つの保存位置

基準seedはセーブデータ固有の値です。復元ボーナスとスキルは同じ基準seedを使いますが、 現在位置は別々のカウンターとしてセーブデータに保存されます。

01

検索で基準seed・復元カウンターを特定

  1. 「ボーナスをリセットして再復元」の直前でセーブします。
  2. 同じ武器で「ボーナスをリセットして再復元」を連続6回行い、各回の5枠を記録します。
  3. セーブせずにゲームを終了し、「seed・復元カウンター検索」タブへ入力します。

02

結果からスキルカウンターを特定

  1. 同じ元セーブをロードします。
  2. 同じ武器で「スキル再付与」を連続2回以上行い、シリーズ・グループスキルを記録します。
  3. セーブせずにゲームを終了し、「スキルカウンター特定」タブへ入力します。

03

未来予測から欲しい結果を採用

  1. 「復元ボーナス未来予測」または「スキル未来予測」タブで、狙う武器種・属性を登録します。
  2. ゲーム内で再復元またはスキル再付与を行い、欲しい結果が出る「○回先」まで進めます。
  3. 欲しい結果を確認して採用し、セーブします。
  4. その行の「ここを0にする」を押すと、セーブした位置から続きを予測できます。

SAVE MATERIALS

複数武器を比較して、効率よく厳選する

スキルカウンターは全武器で共有されます。先に複数の武器種・属性を登録し、欲しい結果が出る位置をまとめて確認すると、素材と時間を節約できます。

抽選するたびにカウンターは進みます。観測後にセーブすると進んだ位置が保存されるため、元の状態に戻す場合はセーブせずにゲームを終了してください。

FIND BASE STATE

基準seed＋復元ボーナスカウンター検索

セーブ地点から連続して確認した復元ボーナスを入力し、基準seedとその時点の復元ボーナスカウンターを同時に検索します。

COUNTER RANGE

復元ボーナスカウンターはセーブごとに異なります

実測サンプルの 475–485 は全ユーザー共通ではありません。これまでこのセーブデータで復元ボーナスを抽選した、おおよその累計回数が含まれるように探索範囲を設定してください。

復元ボーナスカウンターの探索範囲・実行設定

開始・終了は手動でも変更できます。正確な現在値は検索結果から決まります。範囲幅を広げると探索時間もほぼ比例して増えます。

    LOTTERY METHOD

    ゲーム内で行う再復元

    まずリセットで希望の構成を探し、その構成を引き継いでEX厳選へ進めます。

    再復元の方法

    EX未厳選武器ごとの現在構成

    登録した各武器について、ゲーム画面の左から順に5枠の系統を選びます。II・III・EXの入力は不要です。

    武器ごとに構成を入力

    同じ武器種・属性でも、別の武器プロファイルとして複数登録できます。弓には斬れ味・装填系、ボウガンには属性系の構成を使用できません。

    REGISTERED TARGETS

    登録した武器種・属性を一覧比較

    リセット抽選は武器種・属性が同じなら同じ結果です。「ボーナスを同じ構成で再復元」でEXを厳選する場合は、同じ武器種・属性の別武器も表示名を付けて複数登録できます。

    EX数で絞り込む

    いずれかの登録武器が最低EX数を満たす行だけ表示します。

    「この位置を新しい0にする」は、ゲーム内でその結果まで進めてセーブした場合に使用してください。リセット結果の「この構成でEX厳選へ」は、保存後カウンターと5枠構成をまとめて引き継ぎます。
