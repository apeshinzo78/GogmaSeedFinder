# 公開ロードマップ

更新日: 2026-08-24

## 公開時の目標

PS5ユーザーがゲーム内部値やMODを使わず、次の流れをブラウザだけで完了できることを公開版の目標とする。

1. 巨戟復元強化の直前でセーブする
2. 「ボーナスをリセットして再復元」を連続6回観測する
3. セーブせずにゲームを終了する
4. 武器種・属性・6回分の5枠をWebへ入力する
5. セーブ時点の状態候補を特定する
6. セーブ地点を0として未来の復元ボーナスを表示し、目的構成が何回先か確認する

公開初期版の実測保証は「ボーナスをリセットして再復元」に限定する。「ボーナスを同じ構成で再復元」とスキル未来予測はGARP式まで実装済みだが、独立したゲーム実測が取れるまでは試験機能として扱う。通常アーティア強化とスクリーンショットOCRは初期版の公開条件に含めない。

- 近接10候補、弓8候補、ボウガン8候補
- スラッシュアックス、弓、ヘビィボウガンの実測golden vector
- 既知counter探索と有界の未知counter探索
- Rust CLI、WASM、Web Workerによるブラウザ探索
- 武器種・属性・ゲーム内日本語名による手入力UI
- 探索の進捗表示、中止、複数Worker
- seed/counter候補から最大1,000回の未来予測
- 実測先頭照合、別武器・属性への再計算、順不同の希望構成フィルター
- 通常画面ではセーブ地点を0とし、絶対counterを内部探索設定へ移動
- 複数の武器種・属性を同じ起点から横並びで表示する比較表
- 用途別5タブと、基準seed・復元ボーナスカウンター・スキルカウンターの共通状態表示
- 最大16件の武器プロファイルと共通状態の端末内保存
- 武器ごとの5枠構成を使う「同じ構成で再復元」の未来予測（GARP式、実測待ち）
- リセット結果から保存後カウンターと構成を引き継ぐ「この構成でEX厳選へ」
- 比較表の5枠1列表示、表内スクロール、何回先／保存後状態の固定列
- 武器個体が違っても、武器種・属性が同じなら結果が一致することの実測
- 復元・スキルの両位置を保持する`GSF2`セーブ状態コード（`GSF1`も読み込み可）
- 復元ボーナスの系統色を保ったEX強調
- 既知seed上のスキルcounter探索と未来予測（GARP golden vectorまで検証）
- グループ「ヌシの魂」と、選択したシリーズスキルの強調表示
- スキル未来表の保存後セーブ状態コード

公開前に必要:

- PS5向け観測手順とcounter範囲の分かりやすい設定
- 公開範囲外の機能を誤操作できないUI
- ライセンス、出典、CI、GitHub Pages
- PCとスマートフォンでの実機検証

## Phase 0: 現在の検証状態を固定する

目安: 1開発セッション

- 現在のRust・WASM・Web・fixtureを最初の基準コミットにまとめる
- 全fixtureの出典、日時、武器種、属性、画像SHA-256を再確認する
- ライトボウガンはヘビィと同じ8候補としてテストを維持する
- 可能ならライトボウガンでも6回分を取得し、独立した実測fixtureを追加する
- 近接・弓・ボウガンの不可能な候補が検索前に拒否されることを固定する

完了条件:

- `cargo test --workspace --all-targets`が成功する
- `cargo clippy --workspace --all-targets -- -D warnings`が成功する
- WASMをクリーン状態から再生成できる
- 実測3系列の30枠がすべて一致する

## Phase 1: 未来予測を完成させる

状態: 完了（2026-08-23）

目安: 2開発セッション

- `baseSeed`、武器種、属性、`gogmaCounter`から将来の連続結果を生成するAPIを追加する
- 検索結果を選択すると、次の50～100回を表形式で表示する
- 1回ごとに5枠、何回先か、必要な操作回数を表示する
- 攻撃・会心・属性・斬れ味／装填の条件で未来結果を絞り込めるようにする
- 検索に使った観測結果と予測の先頭6回が一致することを自動確認する
- 武器種や属性を変えた場合も、同じ`baseSeed`から対応する未来を再計算できるようにする
- 複数の武器種・属性の未来を同じ「何回先」で比較する
- 中間の結果を採用してセーブした後、セーブ状態コードから新しい起点として再開する

完了条件:

- スラアク・弓・ヘビィの各fixtureで、観測済み6回と予測先頭6回が一致する
- 条件検索で最初に一致する回数を正しく表示する
- ユーザーが内部IDを入力する必要がない

## Phase 2: PS5向け探索フローを完成させる

状態: 進行中（セーブ地点の相対0表示まで完了）

目安: 2～3開発セッション

- 画面上の用語を「seed」「counter」中心から、ゲーム内操作中心の説明へ変更する（通常画面は完了）
- 通常入力からcounter開始・終了を隠す（完了）
- 内部探索範囲を「標準」「広め」「詳細設定」のプリセットにする
- 一致候補が0件、1件、複数件の場合に次の操作を明示する
- 複数候補の場合は追加の1回を入力して再絞り込みできるようにする
- ブラウザを閉じても観測入力と探索結果を端末内へ一時保存できるようにする
- 探索条件をJSONとして書き出し・読み込みできるようにする
- セーブせず終了するタイミングと、予測上の「1回目」がどこを指すかを図付きで説明する

性能課題:

- 現在の11 counter探索を基準にPC・スマートフォンで測定する
- 広いcounter範囲では段階探索、観測追加、範囲分割のどれが有効か比較する
- ブラウザが固まらず、中止後すぐ操作へ戻れることを確認する
- 端末性能に応じてWorker数とチャンクサイズを自動調整する

完了条件:

- MODを知らないテスターが説明だけで6回分を入力できる
- 候補が複数でも、画面の案内だけで追加観測へ進める
- 探索中も画面操作と中止が機能する
- PS5ユーザーが`counterGate`を入力する必要がない

## Phase 5: 限定ベータ

目安: 1週間または5～10人の検証完了まで

- PC版とPS5版の利用者へ限定公開する
- 武器種、属性、観測6回、特定結果、実際に一致した未来位置を報告できるテンプレートを用意する
- 近接、弓、ヘビィ、ライトから最低1件ずつ成功例を集める
- 候補0件、複数候補、低性能端末、途中キャンセルを重点的に確認する
- 不一致時は画像、入力JSON、ツールversionを保存し、RNG不一致と入力ミスを切り分ける

ベータ終了条件:

- PS5で少なくとも3つの独立したセーブ状態からseed/counterを特定できる
- 特定後の未来結果がゲーム内で再現する
- 重大な誤予測、データ消失、探索停止不能が0件
- 既知の制限と回避策が公開ページに整理されている

## 公開を止める条件

次のどれかが残る場合は、一般公開せず限定ベータを継続する。

- 同じ入力で実行ごとに候補が変わる
- 実測fixtureと未来予測が一致しない
- 武器種ごとの候補プールを誤って混在させる
- セーブせず終了した場合のcounter位置を正しく説明できない
- PS5ユーザーが入手不能な内部値を必須入力として要求される
- 公開ライセンスまたは第三者コード・データの扱いが未決定
